# alvo

Protótipo do **alvo AI** — copiloto operacional sobre o ERP.

## Apps

| Pasta | Descrição |
|-------|-----------|
| `web/` | Frontend Next.js (App Router) + TypeScript + Tailwind + shadcn/ui |

## Desenvolvimento

```bash
cd web
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Firebase App Hosting

- Projeto: `alvo-f44bd`
- Backend id: `alvo-web`
- Root directory: `web`

Configuração em `firebase.json` e `web/apphosting.yaml`.
